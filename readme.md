# Bubble - Grid Area Layout

Proyecto web estático desarrollado con HTML y CSS que implementa un diseño moderno basado en **CSS Grid** y **Flexbox**.  

![Demo](/imagenes/demo.gif)  
[Visita Bubble](https://grid-area-mina-45b.netlify.app/) ![Icono Bubble](/imagenes/bubble-icon.svg)

## Descripción

**Bubble** es una maqueta de tienda online enfocada en ropa y accesorios con un estilo moderno. El diseño combina efectos visuales como animaciones tipo *glitch*, uso de tipografías personalizadas y una estructura responsive.

Este proyecto está orientado a practicar:
- Maquetación con **CSS Grid**
- Uso de **Flexbox**
- Diseño responsive con **media queries**
- Integración de iconos externos (Bootstrap Icons)
- Estilización avanzada con CSS (blur, sombras, animaciones)

---

## Características

- Responsive (adaptado a dispositivos móviles)
- Layout basado en **Grid Areas**
- Animación "glitch" en el título
- Sección lateral con ofertas y enlaces
- Efectos visuales (hover, sombras)

---

## Tecnologías utilizadas

- HTML5
- CSS3
- CSS Grid
- Flexbox
- Google Fonts
- Bootstrap Icons (CDN)

---

## Responsive Design

El diseño se adapta automáticamente a pantallas pequeñas:

- Cambio de layout (aside pasa debajo del contenido)
- Activación de iconos sociales en navegación
- Ajuste de tamaños y espaciado
- Cambio de colores de fondo
